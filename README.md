# 🎟️ EventHub – Online Event Ticket Booking System

## 📌 Project Overview

EventHub is an Online Event Ticket Booking System developed as a web-based project. It allows users to register, log in, explore available events, view event details, book tickets, make a demo online payment, and receive booking confirmation.

## 🎯 Objectives

- Provide an easy online event booking process
- Allow users to register and log in
- Display available events with complete details
- Allow users to select the number of tickets
- Automatically calculate the total booking amount
- Provide UPI and Card demo payment options
- Display booking confirmation after successful payment

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Google Maps
